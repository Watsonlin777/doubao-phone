# 手机搭建

## 1. 开无线调试

1. 设置 → 关于手机 → 连点版本号，打开开发者选项。
2. 开发者选项 → 无线调试，打开。
3. 在无线调试里做配对：拿到配对端口、连接端口、配对码。
4. 配对码只用一次，用完即废，不要截图发给别人、不要记在公开地方。
5. 随时可以在开发者选项里撤销 adb 授权。

## 2. 起反向隧道（手机在 NAT 后面时用）

手机通常不在公网、也不在服务器的局域网里，服务器没法直接发起连接，所以要手机主动向外建隧道：

- 手机 Termux 里起 sshd（默认端口按你 Termux 的设置来）。
- 手机用 autossh 把 Termux sshd 的端口反向转发到服务器本机。
- 服务器再通过本机端口连回手机。

模板见 `scripts/phone/reverse-tunnel.sh`，里面只有占位符：服务器地址、服务器用户、密钥路径、端口都要换成你自己的。隧道断了，远程控机就断了；手机重启后要重起隧道（可以用 Termux:Boot 做开机自启，按你自己的习惯来，不在本项目里强制规定）。

## 3. 手机上要装的东西

- 微信等你要操作的应用，正常登录（不要在测试机、云手机上用你主号做高风险操作，先在文件传输助手里测）。
- 微信输入法（中文输入走它，见 skill）：要已经启用，且在微信里不会弹出首次使用同意页。
- 不要为了测试去装百度输入法并点同意：实测里一切过去就会弹出首次使用隐私同意全屏页，不要替用户点同意。

## 4. 手机上不要做的事

- 不要把开发者选项、无线调试、adb 授权长期开着不管：不用的时候关掉，授权也可以撤销。
- 不要把配对码、密钥、服务器地址发到群聊、公开仓库、截图里。
- 任务进行中，手机最好不要同时被别人手动操作：agent 读屏、点按和人手动点按会互相打架。
  如果打开应用后前台不是目标会话、且那个会话输入框里还有用户自己的草稿，
  就停下，不要导航、不要点按、不要复述草稿，先把现状报给用户，等用户决定。
