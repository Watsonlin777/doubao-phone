# 给 Hermes 的任务提示词模板

把下面这段按你的目标改一改，再发给 Hermes。先在文件传输助手里测，再碰真人会话。

```
用 phone_exec 和 phone-wechat-send skill，完成一次测试，只做这一次，不要重复发送。
任务：打开微信，只打开这一个会话，发送前必须先读屏核对顶部标题确实是，
标题不对就立刻停下，不要在别的会话里输入或发送。
确认标题无误后，输入并发送恰好一条消息，内容是：。
中文输入按 skill 走微信输入法拼音加空格的路，不要直接输中文，不要切百度输入法。
整个过程按 skill 的阶段通知一节，每步开头先用 shell 发一条系统通知，
标题是 Hermes 手机任务，标签是 hermes-phone-task，正文只写阶段，不要用 Termux 通知。
发送后再次读屏，确认聊天里出现了一条新发出的，
输入法已恢复回原始输入法，再结束并汇报是否成功、标题核对结果、阶段通知是否发出、以及发送后看到的新消息。
整个任务只发一条消息，成功后不要再发第二条。
```

## 补发模板（上一次超时、输入框里已有文字时用）

```
用 phone_exec 和 phone-wechat-send skill，完成一次补发测试，只做这一次。
重要前提：微信会话的输入框里已经有，不要再输任何文字，
不要输拼音，不要清空输入框，不要切输入法去输入。
第一步先读屏核对两点：顶部标题确实是，输入框里确实恰好是。
如果标题不对或者输入框为空或者内容不是，立刻停下汇报，不要输入，不要发送。
第二步按 skill 的阶段通知一节，用 shell 发一条系统通知，标题是 Hermes 手机任务，
标签是 hermes-phone-task，正文只写阶段，不要用 Termux 通知。
第三步点一次发送按钮，读屏核对一次：如果聊天底部出现一条新发出的且输入框已空，
就算成功，不要再点发送；如果输入框里还有且没有新气泡，最多再点一次发送。
第四步把输入法恢复回原始输入法，用设置核对一次确认生效。
最后发一条阶段已完成通知，再结束汇报是否成功、标题核对结果、新气泡情况、输入法恢复结果。
不要反复等待和重复读屏，核对一次就结束。
```
